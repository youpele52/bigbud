# v0.4.0-beta.2 release report

Date: 2026-11-20

## Outcome

`v0.4.0-beta.2` is published as a GitHub prerelease. Every job in release run
[44708446414](https://github.com/youpele52/bigbud/actions/runs/44708446414) passed:

- Preflight
- Native resource cleanup on every platform
- The server workspace agent builds
- The remote agent builds
- The remote backend graph builds
- The desktop builds for macOS, Windows and Linux
- Publish GitHub Release

macOS notarization succeeded, which confirms that the Apple Developer Program License Agreement is now
accepted. That missing agreement was the cause of the macOS failures in the beta.1 run.
