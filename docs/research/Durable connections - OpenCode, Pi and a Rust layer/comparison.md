## What the tables say

1. **A durable agent is a process that owns the work and writes a checkpoint before the risky step.** OpenCode does this with a session claim and a continue prompt. Pi Durable does it with a task phase and a replay policy. The Pi coding agent does neither for the running turn. A socket that stays open does not do it either.
2. **On the connection, bigbud is already ahead of both shipping products.** Neither OpenCode nor the Pi coding agent replays a live stream from a cursor. bigbud does, from a global SQLite sequence, on both routes. Durable Streams ([protocol](https://github.com/durable-streams/durable-streams/blob/main/PROTOCOL.md)) and SSE `Last-Event-ID` ([HTML §9.2.4](https://html.spec.whatwg.org/multipage/server-sent-events.html#the-last-event-id-header)) describe that same offset-resume shape. Pi Durable's watch API deliberately does not replay; it sends the current view.
3. **Pi, as bigbud runs it, is the weak agent.** Its turn is tied to the client's stdin. bigbud is that client, so a backend crash ends every running Pi turn. Pi Durable shows what the authors built when they wanted that to stop, and they built it beside the CLI, not inside it.
4. **OpenCode is the strong agent, and bigbud already borrows it.** Because V2 uses the shared `opencode serve --service` daemon, those turns survive a bigbud backend crash. The resume is at-least-once: the model is asked to continue, and a tool can run twice.
5. **Sleep stops local work in all four.** None keep a local agent running while the machine is asleep. The recoverable behavior is: notice the wake, then continue from the last checkpoint when that is safe.

OpenCode, Pi Durable, Temporal ([event history](https://docs.temporal.io/workflow-execution/event)) and Phoenix LiveView ([rejoin from server state](https://hexdocs.pm/phoenix_live_view/js-interop.html#handling-server-pushed-events)) agree on one point. Clients are disposable. Durability sits with the owner of the work and its log. None of them keep a client's socket alive across a restart of that owner.
