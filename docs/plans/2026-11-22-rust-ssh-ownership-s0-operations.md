**Static evidence only; S0 remains open.** Read with the [implementation plan](2026-11-22-rust-ssh-ownership-plan.md) and [qualification ledger](2026-11-22-rust-ssh-ownership-s0-ledger.md). Operation names below refer to the plan's catalog, not a frozen wire schema. No recorder, live SSH, timing, fixture, or release qualification was run for this document.

## How to read the limits and errors

- Values are legacy source settings, not proposed owner defaults. An execution timeout is not an end-to-end deadline: [`runSshCommand`](../../apps/server/src/ssh/sshProcess.ts#L28-L49) checks abort before and after readiness, then launches; it can do a separate host-trust inspection on failure. It does not pass the caller's signal into readiness. Callers that use direct `spawn`, `execFile`, a PTY adapter or the local auth helper do not inherit these process-runner defaults.
- [`runProcess`](../../apps/server/src/utils/processRunner.ts#L122-L290) defaults to 60 s and 8 MiB **per stdout/stderr stream**, overflow error, and failure on nonzero unless explicitly allowed. Truncate mode keeps a prefix and reports flags; a stderr-tail or streaming callback is a different retention contract. Timeout normally rejects; timeout need not be returned as a result. Abort/timeout of the local transport does not prove the remote command, particularly a mutation, did not execute.
- [`sshLocalCommand`](../../apps/server/src/ssh/sshLocalCommand.ts#L14-L24) gives readiness 10 s, individual local probes 5 s and unlock 20 s; its sync path uses a 1 MiB `maxBuffer`. The async path tests accumulated string length before appending a whole chunk, not a strict 1 MiB byte cap ([implementation](../../apps/server/src/ssh/sshLocalCommand.ts#L60-L142)). Legacy error names, exit codes and HTTP statuses below are layer-specific, not proposed wire codes. `Not found in this path` is not a claim about all callers or platforms.

## C09: remote agent lifecycle and proxy

The [diagnosed command wrapper](../../apps/server/src/remote-agent/remoteAgentDiagnostics.ts#L94-L129) collects in truncate mode with a process buffer of at least 64 KiB, keeps a 64 KiB stderr tail during capture, and enforces the action-specific stdout bound after collection. It raises `RemoteAgentRemoteCommandError` for bad returned exit/timeout/signal or oversized stdout, with stage and up to 8 KiB sanitized diagnostic tail for process failures. Runner rejections can occur before the wrapper receives a result. In this section the stated caps for diagnosed commands are **accepted stdout**, not necessarily capture allocation.
