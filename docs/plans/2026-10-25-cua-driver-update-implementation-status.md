**Slice 8: guard control channel over `bigbud-protocol` (M1.guard, M4.stop; Rust only).**

- Transport: the guard's stdin/stdout pipe pair, private to the spawning Electron process (process lifetime is the channel's only authentication; frame contents never authenticate). 4-byte big-endian length + protobuf `v1.Frame`, `Channel::Control` (64 KiB bound checked before payload allocation; data-channel frames refused). `roles/guard_control/{framing,session,channel}.rs`.
- Guard writes `Hello` first (role `guard`, protocol 1.0, `computer-use-stage1-v1`, frame limits, `guard-<pid>-<nanos>` instance). - Guard internals: storage lane publishes a `GuardStatusSnapshot` (record clone, `denial_persisted`, `storage_ok`) through `GuardServiceControl::status()` after every flush (`retained_retirement/status.rs`, `runtime.rs`); `NoticeState::text` is crate-visible.
