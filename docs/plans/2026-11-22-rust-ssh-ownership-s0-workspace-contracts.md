## Authority before operands

- **Normalize without changing authority.** [Base target resolution](/Users/youpele/DevWorld/bigbud/packages/contracts/src/core/baseSchemas.ts#L14) and the [SSH parser](/Users/youpele/DevWorld/bigbud/apps/server/src/ssh/sshExecutionTarget.ts#L20) preserve a target ID alongside parsed fields: `ssh:<alias-or-destination>` is opaque to the parser until OpenSSH interprets it, while structured IDs use the first `URLSearchParams` value and trim fields; unrecognized auth/transport become absent. Changing the transport preserves other params, not a canonical equivalence proof. Freeze both persisted-ID behavior and a distinct owner descriptor covering effective user, host/port, trust name, ordered identities, auth and route; separately bind the selected product lane, workspace and generation. Decide equivalent spellings and legacy ID migration before sharing disconnect state or a master; never collapse identities merely because they resolve to one host. The [proof transport](/Users/youpele/DevWorld/bigbud/crates/bigbud-ssh-owner/src/bin/ssh_owner/transport.rs#L60) binds one IPv4 loopback endpoint, explicit key/trust files and an optional startup root. Its [config resolver](/Users/youpele/DevWorld/bigbud/crates/bigbud-ssh-owner/src/bin/ssh_owner/config.rs) supports private fixture config sources, not arbitrary saved target IDs, IPv6, ambient agents or routed targets.
- **Picker is not workspace authority.** The [picker RPC](/Users/youpele/DevWorld/bigbud/apps/server/src/ws/wsRemoteFolders.ts) takes a selected target and optional remote folder before a workspace exists. Home/remote folder discovery is not a workspace handle, write permission, or authorization to watch. Workspace verbs need a backend-authorized target/root and relative operand; monitor resolves a saved active project and a caller lease. The [proof client](/Users/youpele/DevWorld/bigbud/apps/server/src/ssh/sshOwnerPickerProof.client.session.ts#L139) and [Rust grants](/Users/youpele/DevWorld/bigbud/crates/bigbud-ssh-owner/src/bin/ssh_owner/owner_grants.rs#L37) bind one-shot requests/digests in an isolated dispatcher; a fixture-provided root and a digest do not establish product grant issuance. An authenticated `/ws` token alone is not a workspace grant. No caller supplies remote scripts, arbitrary cwd, executable, env, or stdin for reads/monitor/control.
- **Classify by actual graph edge.** D (packaged desktop), V-E/V-B (Electron/Bun dev) and N (standalone Node) initiate through their backend. R (deployed Linux GNU x64/arm64) also registers shared picker/verification handlers and shares workspace services; R's local workspaces are account-local, and its configured agent lane is separate. Its outbound deployment/client-relay refusals do not prove denial of shared SSH actions. The R coordinator's paired relay is a separate authority; inbound relay endpoints, agent endpoint jobs and mobile viewers are not initiating SSH owners. See [profile role evidence](/Users/youpele/DevWorld/bigbud/docs/plans/2026-11-22-rust-ssh-ownership-s0-profiles.md). Classify each workspace request through the [workspace runtime](/Users/youpele/DevWorld/bigbud/apps/server/src/workspace-runtime/Layers/WorkspaceRuntime.ts#L23) and [tool router](/Users/youpele/DevWorld/bigbud/apps/server/src/tool-transport/toolTransport.ts#L49): agent workspace RPCs stay on an existing proxy; local work stays local. In contrast, the fallback `WorkspaceEntries` nonlocal directory/index code calls the SSH layer directly, so an ID with `transport=agent` alone does not prove the actual edge. The [optional proof composition](/Users/youpele/DevWorld/bigbud/apps/server/src/ssh/sshOwnerPickerProof.workspace.integration.ts) is not supplied by normal server startup. Once an owner is selected, owner errors must not select a legacy runner.

## What must be decided or proved next

1. **Byte budgets are not interchangeable.** The [private wire](/Users/youpele/DevWorld/bigbud/protocol/ssh-owner/README.md) has 64 KiB client→owner and 8 MiB owner→client payload limits. The 48 KiB proof write cap is content bytes inside a small framed request, not a product limit or permission to advertise 64 KiB content. The [editor](/Users/youpele/DevWorld/bigbud/apps/web/src/components/files/fileEditDrafts.state.ts#L3) and [agent write adapter](/Users/youpele/DevWorld/bigbud/apps/server/src/workspace-runtime/Layers/WorkspaceRuntime.remote.write.ts#L21) use 512 KiB (UTF-8), which the [agent also enforces](/Users/youpele/DevWorld/bigbud/crates/bigbud-remote-agent/src/workspace/core.rs#L27). Neither supplies a general direct-SSH input cap. Freeze per-caller compatibility and a reviewed bounded content path or explicit compatibility decision before activation. Golden cases: 48 KiB and +1, multibyte text at both boundaries, framed overhead with max path/IDs, 512 KiB and +1 on applicable lanes, slow stdin reader, interrupted partial input, and no side effect for rejected sizes. Likewise decide how to retain legacy 16 MiB index behavior without an oversized one-frame reply.
2. **Scope and typed outcomes.** Freeze TS/Rust vectors binding issuer, profile/epoch, target generation, verb, root, normalized path/query/flags and write-content digest. Test picker→workspace, read→write, watch/monitor→shell, foreign scope, replay and lost reply with zero unauthorized launch, write, prompt or teardown. Cover intermediate and final path resolution on the execution host, including static symlink, concurrent path replacement, platform prefixes and junction/reparse behavior as applicable. The proof's POSIX checks are not race-safe containment evidence. Retain distinctions among not-dispatched, terminal/refusal, transport unavailable/lost, disconnected, timeout, overflow/partial and unknown mutation; the public [RPC mapping](/Users/youpele/DevWorld/bigbud/apps/server/src/ws/wsRpcHandlers.workspace.ts#L21) is not the private typed contract. Never turn a refusal into an empty result or infer rollback from a missing reply.
3. **Lifecycle and role evidence.** On authorized disposable fixtures later, record actual handler/issuer, profile artifact, target/lane, redacted executable ancestry, launch counts, cap/outcome and cancellation/teardown times per verb. Include D/V-E/V-B/N and both R graph architectures, admitted picker vs denied grant, local vs direct vs agent-backed workspace, status coalescing and stale generation, slow watch consumer, and no launch after durable Disconnect/rebind. Do not infer native watch credits, remote cancellation, or in-flight reconnect from finished snapshots or fresh reads. Shared MCP/Pi fixed tools require their own G2 caller and per-step authorization (including edit/patch); callback raw-process envelopes and interactive shell are not workspace verbs.
4. **Transfer exclusion.** `transferStream` and `packagedRsync` remain reserved for a future native worker; the S3 fixture is limited to native stream/cancel evidence. No upload/download, recursive copy, rsync packaging/transport launch, publication, drag/drop, transfer staging or TS byte relay is authorized here. Range read, basic overwrite and an existing agent proxy do not qualify file transfer. The [dependent transfer plan](/Users/youpele/DevWorld/bigbud/docs/plans/2026-11-21-remote-file-transfer-rsync-plan.md) requires S4 accepted for the exact build before M0 and separate transfer qualification after that. Neither this map nor the isolated proof meets that gate.
