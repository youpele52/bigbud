# Design prototypes

Keep standalone HTML mockups, interactive demos, and visual design experiments here.
These are exploratory examples, not production app pages or implementation plans.

- Use descriptive, dated filenames with the appropriate extension, such as `2026-10-22-thread-picker.html`, `2026-10-22-thread-picker.md`, or `2026-10-22-thread-picker.svg`. This convention applies to other file types too.
- Keep any local assets alongside the prototype, using a subfolder when needed.
- Link to related plans in `docs/plans/` when useful.
- Do not include credentials or private user data.

Open standalone HTML files directly in a browser unless the prototype documents a local-server requirement.
