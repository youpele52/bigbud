# bigbud workspace language

bigbud distinguishes project folders from the remote environments you connect to.

## Language

**Project**:
A folder of work, such as an application or repository, on your computer or within a remote environment.

**Remote workspace**:
A remote working environment you connect to from bigbud, which can contain one or more project folders.
_Avoid_: Remote project when referring to a remote environment or its sidebar entry.
