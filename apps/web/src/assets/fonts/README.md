# DM Sans

Unmodified variable fonts from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/dmsans),
licensed under the SIL Open Font License 1.1 (see `OFL-DMSans.txt`).

The inline HTML renderer embeds these assets as data URLs so its DM Sans font matches
the application without permitting remote font requests. Both upright and italic
faces include the optical-size and weight axes.
